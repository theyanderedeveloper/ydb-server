Faq

Vanilla's Vault has already several possible questions answered:

Why is the domain theyandere.dev? Is it connected to Yandere Simulator?
Theyandere.dev, as well as any other projects built with the same domain are NOT connected to YandereDev or Yandere Simulator in any way. The domain was chosen in ~2017, however acquired just recently.
How to publish a file here?
For now, there is no direct way to publish files, but there are plans for the future
Will there be a mobile/desktop application?
Yes, after Ancorix will be finished, the desktop app will begin development, until then use the web version.
What is this database for and what kind of content does it host?
The database hosts any SFW user content.
Is the content hosted here free to download and view?
Absolutely. Any data stored on the database is accessible and free to download and view for anyone! The only limit could be the content's license, which could forbid content from being modified, used commercially, or used without permissions. It is recommended for you to look at the license of content first.
Where can I find social media channels or community links?
All of the socials of TheYandereDev are here.
How is my personal data handled and is my privacy protected here?
User published and not hidden content is visible for anyone. You can request the files to be stored in a hidden, but still accessible with a direct link directory. The privacy policy is here. No user data other than the requested files is currently stored on server. This entry will change when the account system will be added.
Are there any rules and guidelines for using the database?
There are a few simple rules:
  1. No NSFW content: No gore, no porn, no dark humour (it sometimes falls into the NSFW category), etc.
  2. No illegal content: No drug recipes, no CSAM, no malware, etc.
  3. No offensive content: No racism, no antisemitism, no discrimination, etc.
  4. No personal information: Any data that could leak your location is not allowed. While metadata is purged from all files, the location could still be tracked from just an image.
